# BetaAchievement 成就说明

本插件还原了 Minecraft Beta 1.7.3 原版的 16 个成就。下表列出了每个成就的 ID、中文名、英文名、获取要求以及插件的实际判断方式。

## 轮次与计时

每名玩家拥有独立的多轮挑战记录。第一轮和后续轮次都以本轮第一次获得 `openInventory` 的时间作为起点，第 16 个成就完成时结束计时。计时按服务器真实时间连续计算，离线及服务器关闭期间也会计入耗时。每轮每个成就分别记录：

- `completed_at_ms`：绝对完成时间。
- `elapsed_ms`：从本轮起点到该成就的累计耗时。
- `split_ms`：距离上一个成就经过的时间。

完成全成就后使用 `/ach run next` 开启下一轮。旧轮次不会被删除。

只有完成过至少一轮 16/16 的玩家才能使用 `run next` 和 `run abandon`。第 2 轮及以后进入活动状态后，若超过 12 小时仍未完成，该活动轮次及本轮 `run_progress` 数据会被自动删除；第 1 轮和所有已完成轮次不会被该超时删除。

## 通用判断规则

- **前置依赖**：除「打开物品栏」外，普通游戏触发都需要先解锁其前置成就（上表最后一列）；未解锁前置时即使满足条件也不会解锁。使用 `/achievement grant` 命令授予成就时，会自动补全缺失的前置成就。
- **合成类成就**：通过监听 `Packet102WindowClick` 数据包，检测玩家在工作台输出槽（slot 0）点击取出的成品物品 ID 来判断，而不是依赖合成配方事件。
- **熔炉类成就**：通过监听同一数据包，检测玩家在熔炉结果槽（slot 2）点击取出的产物物品 ID 来判断。
- **捡取类成就**：通过 `PlayerPickupItemEvent` 检测捡起物品的 ID；其中「打开物品栏」为捡起任意物品即触发。
- **击杀类成就**：记录最近 30 秒内对怪物的玩家攻击者，支持近战、箭、雪球、火球等由玩家发射的投射物；怪物死亡时据此判断击杀者。
- **矿车距离成就**：从玩家上车位置起算三维直线距离，达到 1000 米（1000000 平方）即解锁；更换世界会重新记录起点。
- **特殊成就**：「在铁路上」与「当猪飞的时候」被标记为特殊（special）成就。
